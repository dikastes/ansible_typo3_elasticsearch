# ansible_typo3_elasticsearch
This collection contains roles to build a TYPO3 web server (Apache, MariaDB, FPM) and connect it to an elasticsearch server.

# Installation
Clone the archive.
Install the collection via

```
ansible-galaxy collection install /path/to/repository/slub/typo3_elasticsearch/
```
